Octave - 10 positions

-4 to +5 = freq _ 2^oct

Math:

12 keys x 11 scales x 7 temps x 6 refs = 5,544 tunings

5,544 x 10 oct = 55,440 distinct ranges

Off+Off = infinite

Range: OCT -4 = 15Hz to OCT +5 = 20kHz (wide amp)

So: REF = center, KEY = root, TEMP = tuning, SCALE = filter, OCT = window.
