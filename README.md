2. Temperament (7)

How pure is each interval? Tiny tuning shifts -29 to +34 cents:

Off / Equal - modern piano, all keys same

Pythagorean - pure fifths, medieval bright

Meantone - Renaissance choirs, sweet thirds

Werckmeister 3 - Bach's organ, every key has different mood

19 Tone Equal - microtonal third-tones

Octave (7)

Minus 2 to plus 4. 32Hz to 4186Hz.
